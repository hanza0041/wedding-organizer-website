# ข้อมูลตั้งต้นสำหรับวางแผนงานแต่ง

ค้นเมื่อ 17 พฤศจิกายน 2026 (พ.ศ. 2569) สรุปและออกแบบรายการใหม่เพื่อให้คู่บ่าวสาวพูดคุยและลงมือเตรียมร่วมกัน ไม่คัดลอกข้อความต้นฉบับ

## แหล่งข้อมูล

1. [The Knot — Wedding planning checklist and timeline](https://www.theknot.com/content/12-month-wedding-planning-countdown): ใช้ประกอบลำดับภาพรวม ได้แก่ ตกลงสิ่งสำคัญ งบ จำนวนแขก และสถานที่ ก่อนเลือกทีมงานและรายละเอียด จากนั้นยืนยันการเตรียมก่อนวันจริง
2. [Brides — Wedding planning](https://www.brides.com/story/brides-wedding-checklist-custom-wedding-to-do-list): ใช้เป็นข้อมูลประกอบเรื่องการวางแผนร่วมกับคู่และผู้ให้บริการ ไม่มีการนำราคาเฉลี่ยต่างประเทศมาเป็นงบแนะนำสำหรับไทย
3. [Birevet — ลำดับพิธีแต่งงานไทย](https://birevet.com/th/blog/khantorn-phithi-taeng-ngan-thai): ใช้ประกอบหัวข้อคุยกับครอบครัวเรื่องพิธี เช่น พิธีสงฆ์ ขันหมาก สวมแหวน ไหว้ผู้ใหญ่ รดน้ำสังข์ และยกน้ำชา แต่ละครอบครัวเลือกได้ตามธรรมเนียม ไม่กำหนดว่าต้องจัดทุกพิธี

## การนำมาใช้ในเว็บ

แบ่งเป็น 8 หัวข้อ: ภาพงาน งบ สถานที่และอาหาร แขกและการ์ด พิธีและครอบครัว ชุดและความงาม ทีมงานและบรรยากาศ และวันจริง แต่ละหัวข้อมีคำถามเปิดบทสนทนาที่เขียนขึ้นใหม่ และช่องจดข้อสรุปของคู่บ่าวสาว

สร้างรายการเตรียมงาน 28 รายการใน `lib/planning.mjs` วันครบกำหนดเป็น **ค่าเริ่มต้นที่ออกแบบสำหรับแอป** ไม่ใช่กำหนดตายตัวจากแหล่งข้อมูล คำนวณถอยจากวันแต่งงาน หากช่วงเตรียมสั้น รายการก่อนหน้าจะเริ่มวันนี้โดยไม่ติดสถานะเลยกำหนดตั้งแต่สร้าง ผู้ใช้แก้วันที่ เวลา หมวด ผู้รับผิดชอบ หรือเอารายการที่ไม่ใช้ทิ้งได้

งบเริ่มต้นเป็นศูนย์ (ยังไม่ตั้ง) ไม่สมมติราคา เงินสำรองและความต้องการเฉพาะให้ทั้งคู่ตกลงกัน ไม่มีข้อความสนทนา ผู้ให้บริการ หรือยอดเสร็จปลอม

จดทะเบียนเป็นเรื่องที่เลือกเพิ่มได้ หากต้องการให้สอบถามสำนักงานเขต/อำเภอปลายทางโดยตรง ไม่รวมคำแนะนำเอกสารหรือกฎหมายที่อาจต่างกันตามบุคคล

## Cloudflare

- [Quick Tunnels](https://developers.cloudflare.com/tunnel/get-started/quick-tunnels/): URL ชั่วคราวที่สุ่มขึ้นใหม่ เหมาะสำหรับทดลอง; ใช้ polling แทน SSE เพื่อให้ทำงานร่วมกับ Quick Tunnel ได้
- [Create a locally-managed tunnel](https://developers.cloudflare.com/tunnel/features/locally-managed-tunnels/create-local-tunnel/): Named Tunnel ผูก DNS กับ hostname บนโดเมนที่ควบคุมได้ ทำให้ URL เดิมกลับมาใช้งานได้เมื่อ restart
- [Tunnel run parameters](https://developers.cloudflare.com/tunnel/reference/run-parameters/): รัน remotely-managed tunnel โดยส่ง token ทาง environment แทนการใส่ใน argument

แอปนี้ให้ Cloudflare Tunnel ส่งต่อ HTTP มายัง Node server บนเครื่อง ข้อมูลอยู่ใน SQLite บนเครื่อง ไม่ได้ deploy SQLite ขึ้น Cloudflare Worker เครื่องและ Tunnel ต้องเปิดอยู่จึงใช้งานจากภายนอกได้
